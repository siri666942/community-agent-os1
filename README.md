# Opsie · 阅读营运营助手

Opsie 是面向儿童阅读营的黑客松演示项目。老师可以在同一个工作台查看家长对话和阅读画像，用 AI 生成可编辑的回复，并在发送前进行话术质检；家长可以登录后与老师私聊或在演示群中交流。

## 已实现功能

- **老师与家长聊天**：一个老师、四个家长账号，支持私聊和固定演示群。消息默认保存到本地 SQLite，老师的回复经过发送前审核后送达。
- **AI 回复与质检**：结合当前会话完整历史、所选家长画像和已确认业务口径，生成三条可选择、编辑的回复；对家长敏感消息单独提醒和计数。
- **工作台与画像**：展示今日会话、家长敏感消息次数、高意向用户和今日跟进；根据已有阅读数据展示营期末七天活跃度、意向信号、行为概括和人工标签。工作台支持本机缓存并在后台更新。
- **SOP 与话术口径**：SOP 供静态查阅；“话术与质检”可管理数据库中的标准口径及风险规则，供生成和审核参考。已确认业务政策集中在 `knowledge/business_policy.json`；未确认的价格、优惠和退费政策不会作为确定事实提供给模型。

## 启动演示

默认演示只需 Python，以及已启动并配置模型的 Magpie；无需连接远程数据库。首次在 Windows 上启动：

1. 启动 Magpie，默认地址为 `http://127.0.0.1:3425`，默认模型为 `sophnet/DeepSeek-V4.1-Flash-1017`。
2. 在项目目录运行 `start-opsie.cmd`，然后打开 <http://127.0.0.1:8780/>。脚本首次启动会将纯虚构种子 `data/opsie-demo.sqlite3` 复制到本机 `.dbmcp/opsie-demo.sqlite`，并生成本机账号密码。
3. 老师及四位家长的演示账号密码保存在本机 `.dbmcp/demo-accounts.json`。多台设备访问同一个服务的局域网地址；一台设备也可使用多个独立页面分别登录。

## 当前边界

- 默认 SQLite 的姓名、背景对话和阅读指标均为虚构演示数据；原始 MySQL 记录保持原样，不会自动导入。现场新发的消息保存在本机运行库。
- 阅读指标展示为“营期末七天”，并非当前日历上的近七天。
- 演示群成员固定；尚未接入真实企业微信，也不支持完整的建群、拉人、音视频或文件发送。
- 模型服务和数据库不可用时，相关功能会提示失败；生成候选和老师发送前审核需要等待模型。聊天消息目前仍通过定期查询更新。
- SOP 是只读资料；复杂流程、自动触达、负责人审批和根据修改自动训练模型尚未实现。价格、优惠、退费和部分质检口径仍待业务确认。
- 局域网使用和多台设备互通需在演示现场验证；当前服务适合可信演示网络。

## 项目结构与验证

```text
opsie/                       SQLite/MySQL 数据访问、聊天接口、画像、AI 和质检
data/opsie-demo.sqlite3      不含真实信息的 SQLite 演示种子
web/opsie.html、opsie.js、opsie.css  老师端与家长端
service/                     接入的 Agent 候选整理与质检规则
knowledge/                   SOP、业务口径及历史素材
tests/                       自动测试与真实服务端到端测试
```

运行自动测试和前端语法检查：

```powershell
.\.opsie-venv\Scripts\python.exe -m unittest discover -s tests -q
node --check web/opsie.js
```

SQLite 端到端测试使用独立临时库，不会改动本机演示数据。原 MySQL 联调脚本 `tests/opsie_e2e.py` 仅用于服务端和客户端均处于 MySQL 模式的情况。功能范围和待确认事项见 [功能验收与优化报告](功能验收与优化报告.md)、[业务口径冲突清单](业务口径冲突清单.md)。

仓库中还保留早期 OPC 工单和命令行代码，相关说明见 [工作流说明](WORKFLOW.md) 与 [网页接口说明](web_api/README.md)；当前聊天演示使用上述 Opsie 入口。

## 公司名称 / Company Name

**伴学管家(Banxue Housekeeper)** —— 一家由 1 位人类老板 + MiMo Agent 团队运营的 **AI 社群代运营公司**。

## 一句话项目定位 / One-sentence Value Proposition

**替教育品牌把家长社群管起来:MiMo Agent 团队 7×24 承接社群应答、内容运营、家长分层与转化跟进,人只做闸门拍板——用 1/10 的人力成本,跑出一支不下班的社群运营团队。**

> English: We run parent communities for education brands — MiMo-powered agents handle replies, content, segmentation and follow-ups around the clock, while humans only approve at decision gates. A full community ops team at a fraction of the cost.

## 目标用户 / Target Audience

**B 端客户:有家长社群、缺运营人力的教育产品与机构。**

| 维度 | 描述 |
|---|---|
| 典型客户 | AI 教育 App、教培机构、教育 IP(如绘本/识字/阅读类产品) |
| 画像特征 | 已有 500+ 家长的微信社群,靠老师/班主任兼职运营,响应慢、话术不合规、家长分层靠感觉 |
| 首个客户 | **适趣AI中文**(AI 中文阅读 App):3 个家长群、1,700+ 条真实群聊,21 天阅读训练营 + 两年会员制 |
| 用户收益 | 家长消息有合规应答、每日运营有内容、跟进有名单、成交有留痕;投诉/退款自动升级老板拍板 |

## 产品定价 / Product Pricing

**按社群规模收月服务费(B2B 订阅);不向家长收费。**

| 档位 | 服务范围 | 月服务费 |
|---|---|---|
| **基础版** | 1–2 个社群(≤ 500 家长):AI 应答值守 + 日度运营包 + 质检留痕 | **¥3,980 / 月** |
| **标准版** ⭐首单同款 | 3–5 个社群(500–2,000 家长):基础版全量 + 家长分层跟进 + 成交链路 + 经营周报 | **¥9,800 / 月** |
| **旗舰版** | 6 个社群以上 / 定制 SOP:标准版全量 + 专属知识库 + 周度经营复盘会 | **¥19,800 / 月起** |

- 计费逻辑:覆盖 Agent 运行成本(token)与人工闸门时间后仍有显著毛利(详见《运营成本与商业化分析》)
- 对比人力:一线城市一名社群运营专员月综合成本约 ¥10,000–15,000,且只覆盖 8 小时工作制;标准版以约 1/1 成本覆盖 7×24 + 合规质检 + 数据分层三重职能
- 首单实证:**适趣AI中文 · 社群代运营服务包 · 标准版**,报价→合同→(模拟)收款→交付全链路留痕,见 `output/first_order/`

## 商业价值闭环(30 秒版)

```
家长社群(真实消息进)→ 双 Agent 编制(应答/内容/分层/跟进)→ 合规应答 + 运营包 + 跟进名单出
→ 家长体验与转化提升 → 客户按月续费(订阅制)→ Agent 边际成本趋近于零 → 毛利随规模增长
```

- **收谁的钱**:教育品牌的服务费(订阅),家长端永远免费
- **为什么续费**:每日运营包、40+ 小时经营流水、周报全留痕,效果可审计
- **为什么便宜**:95% 工作由 Agent 自主完成,人只在 9 道闸门上花时间(详见《Agent 组织架构与人机分工》)
